🔧 Migración única de datos — App Integrada (Prototipo)

⚠️ Herramienta de un solo uso. LEE de las dos apps originales (Tabla Quirúrgica y Lista de Espera) y ESCRIBE una sola vez en la base de datos nueva de esta app integrada. Nunca escribe ni modifica nada en las dos bases de datos originales — solo hace lecturas ahí (.once('value')). No se migran las colecciones de usuarios de ninguna de las dos apps originales (usuarios/users): las cuentas de Firebase Auth no se pueden copiar desde el navegador, así que cada persona necesita una cuenta nueva creada desde el panel de administrador de esta app integrada, una vez migrados los datos.

1. Iniciar sesión — Tabla Quirúrgica (origen, solo lectura)

2. Iniciar sesión — Lista de Espera (origen, solo lectura)

3. Iniciar sesión — App Integrada (destino, donde se va a escribir)

4. Vista previa (solo cuenta registros, no escribe nada)








    
5. Ejecutar migración (escribe en la base NUEVA, una sola vez)
